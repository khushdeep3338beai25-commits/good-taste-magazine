
# 🍽️ GOOD TASTE MAGAZINE

### A Digital Editorial Experience for Food, Fashion & Culture

Good Taste Magazine is a modern digital editorial platform that brings together inspiring stories from the worlds of food, fashion, restaurants, and contemporary culture. Designed with elegant typography, immersive imagery, and a clean editorial layout, it offers a refined and engaging browsing experience.

🌐 **Live Website:** https://good-taste-magazine-5ikbldl3f.vercel.app

---

## ✨ Features

- 📰 Modern digital editorial magazine experience
- 🍽️ Curated food, restaurant, fashion, and culture stories
- 📖 Interactive magazine-style homepage
- 🔍 Searchable and filterable story archive
- 🌙 Light and dark theme functionality
- 🖼️ High-quality editorial photography
- 🎨 Elegant typography and minimalist visual design
- 📱 Fully responsive across desktop, tablet, and mobile
- 🧭 Responsive mobile navigation
- 📂 Dedicated homepage and stories pages
- ⚡ Smooth and intuitive browsing experience

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd good-taste-magazine
```

**3. Start a local development server**

```bash
python3 -m http.server 8000
```

**4. Open in your browser**

Visit:

```text
http://localhost:8000
```

You can also open `index.html` directly in your browser.
