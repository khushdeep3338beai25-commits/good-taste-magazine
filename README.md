
# Good Taste Magazine

A modern digital editorial magazine exploring food, fashion, restaurants, and culture through a clean, immersive, and visually engaging experience.

## 🌐 Live Website

[View Live Website](#)

## ✨ Features

- 📰 Modern editorial magazine design
- 🍽️ Food, fashion, restaurants, and culture stories
- 📖 Interactive digital magazine homepage
- 🔍 Searchable and filterable story archive
- 🌙 Light and dark theme toggle
- 📱 Fully responsive design
- 🎨 Elegant typography and minimal layouts
- 🖼️ High-quality editorial imagery
- 📂 Separate homepage and stories pages
- 📱 Responsive mobile navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd good-taste-magazine
   ```

3. Open `index.html` in your browser.

   Alternatively, run a local server:

   ```bash
   python3 -m http.server 8000
   ```

4. Visit `http://localhost:8000`.

## 📄 Pages

- **Home:** Magazine landing page featuring the latest issue and featured stories.
- **Stories:** Explore, search, and filter editorial stories.
